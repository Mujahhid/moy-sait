# مَكْتَبَةُ الْعُلُوم

Тихая библиотека: чтение PDF прямо в браузере, аккаунты, избранное, прогресс чтения,
управление каталогом. Без зависимостей: нужен только Node.js 22.13+ (`npm install` не требуется).

## Запуск локально

```bash
node server.js          # http://localhost:3000
```

Данные (база SQLite и загруженные PDF) лежат в папке `data/`.

## Администратор

- **Первый зарегистрированный пользователь автоматически становится администратором.**
  После деплоя сразу зарегистрируйтесь сами.
- Или задайте `ADMIN_NICK=ваш_ник` — этот ник получит права админа при регистрации/входе.
- Админ видит в профиле кнопку «Управление библиотекой»: добавить книгу (PDF → число страниц
  и обложка определяются автоматически), изменить данные, заменить обложку или PDF, удалить.

## Переменные окружения

| Переменная     | По умолчанию | Назначение                                              |
|----------------|--------------|---------------------------------------------------------|
| `PORT`         | `3000`       | порт сервера (Railway задаёт сам)                       |
| `DATA_DIR`     | `./data`     | где хранить базу и загруженные файлы                    |
| `ADMIN_NICK`   | —            | ник, который станет администратором                     |
| `REGISTRATION` | `open`       | `closed` — закрыть регистрацию после создания аккаунтов |
| `MAX_PDF_MB`   | `200`        | максимальный размер одного PDF                          |
| `HOST`         | `0.0.0.0`    | на каком адресе слушать (за Caddy/nginx — `127.0.0.1`)   |
| `AUTO_BACKUP`  | включено     | `0` — отключить ежедневную копию базы в `backups/`      |

## Деплой на Railway

1. Загрузите проект в GitHub-репозиторий и создайте на Railway сервис из него
   (стартовая команда `npm start` подхватится сама).
2. **Обязательно** добавьте Volume (Settings → Volumes), смонтируйте в `/data`
   и задайте переменную `DATA_DIR=/data` — иначе книги и аккаунты пропадут при каждом деплое.
3. Откройте сайт и сразу зарегистрируйтесь — вы станете админом.
4. По желанию: `REGISTRATION=closed`, если не нужны новые читатели.

## Возможности

- Главная: «Продолжить чтение» и «Новые поступления».
- Библиотека: поиск по названию, автору, переводчику, издательству, теме (работает с кириллицей
  и арабицей без учёта регистра), фильтры по разделу и языку (русский / арабский / English).
- «Мои книги» (хочу прочитать / читаю / прочитано), профиль со статистикой (читаю / прочитано / хочу прочитать), смена пароля.
- Читалка: переход к странице, масштаб, «по ширине», полный экран, ночной режим,
  клавиатура (←/→, PageUp/PageDown, Home/End, +/−, Esc), свайпы на телефоне.
- Прогресс сохраняется на сервере и одинаков на всех устройствах.
- Офлайн: книги можно скачать на устройство (кнопка на карточке или страница «Офлайн» по значку ⬇ в шапке) и читать без интернета.
- Темы оформления: светлая, тёмная, розовая, синяя, зелёная (значок палитры в шапке).
- Чтение требует входа в аккаунт; PDF отдаются только авторизованным пользователям.
