# Переезд на Amvera Cloud

Amvera — российская платформа, похожая на Railway: вы выкладываете код, она сама собирает и запускает сайт,
выдаёт HTTPS-адрес и хранит данные в постоянной папке `/data`. Сервер настраивать не нужно.

Файл настроек `amvera.yml` в репозитории уже готов: Node.js 22, запуск `server.js`, постоянное хранилище `/data`, порт 3000.

> Цены и лимиты Amvera ниже взяты из открытых источников на октябрь 2026 — перед оплатой сверьте их на amvera.ru.
> Для вашего сайта подходит тариф «Начальный» (около 290 ₽/мес, диск 5 ГБ).

## 1. Резервная копия со старого сайта

Войдите админом на Railway → «Профиль» → «Управление библиотекой» → внизу **«Скачать копию»**.
Получите файл `kutubul-backup-….tar` (база, все книги и обложки).

## 2. Проект в Amvera

1. Зарегистрируйтесь на amvera.ru (новым пользователям дают стартовый баланс).
2. Создайте проект, выберите тариф **«Начальный»** (5 ГБ) или выше, если книг будет много. Тип — приложение.
3. Откройте раздел **«Переменные и секреты»** и добавьте:

   | Имя | Значение | Зачем |
   |-----|----------|-------|
   | `DATA_DIR` | `/data` | **обязательно** — иначе книги и аккаунты пропадут при каждой пересборке |
   | `PORT` | `3000` | **обязательно**, должен совпадать с `containerPort` в `amvera.yml` |
   | `MAX_PDF_MB` | `200` | максимальный размер одной книги (по умолчанию 200) |
   | `ADMIN_NICK` | ваш ник | по желанию |

## 3. Загрузка кода

**Через Git** (на компьютере, где установлен git). Точный адрес репозитория покажет Amvera на странице проекта:

```bash
git clone https://github.com/Mujahhid/kutubul-ulum2.git
cd kutubul-ulum2
git remote add amvera <АДРЕС_ИЗ_AMVERA>
git push amvera main:master
```

**Без Git:** на GitHub нажмите Code → Download ZIP, распакуйте и загрузите файлы через веб-интерфейс проекта в Amvera.

Сборка и запуск начнутся сами. Папка `/data` создаётся после **первого успешного** запуска.
Обновление сайта позже — тот же `git push amvera main:master`; данные в `/data` при этом сохраняются.

## 4. Адрес сайта и HTTPS

Вкладка **«Домены»** → «Добавить доменное имя» → бесплатный домен Amvera (вида `…amvera.tech`) с типом подключения **HTTPS**.
Сертификат выпускается до ~10 минут. Со своим доменом — вариант «Собственный домен»: Amvera покажет, какие A-/CNAME- и TXT-записи создать.
HTTPS нужен, чтобы работали скачивание книг и чтение без интернета.

## 5. Перенос данных

1. Откройте новый сайт и зарегистрируйтесь (первый пользователь становится админом).
2. «Профиль» → «Управление библиотекой» → **«Восстановить из копии»** → выберите `.tar` из п. 1.
3. Сайт перезапустится сам (до минуты), страница обновится. Войдите **прежним ником и паролем**.
   Если сайт не вернулся за пару минут — нажмите «Перезапустить» в панели Amvera: данные применяются при запуске.
4. Проверьте книги, закладки и прогресс. Старые данные нового сайта сохранены в `/data/before-restore` —
   после проверки их можно удалить через файловый менеджер `/data` в панели Amvera, чтобы освободить место.

Читателям при смене адреса придётся один раз войти заново (сессия привязана к адресу); аккаунты и данные сохранятся.
Railway отключайте после того, как убедитесь, что всё работает.

## Возможные проблемы

- **Не загружаются большие книги** (ошибка 413 или обрыв). Максимальный размер запроса на Amvera задаётся тарифом входящего трафика
  в панели проекта — проверьте его или спросите поддержку. Я не нашёл в документации конкретных цифр.
- **Ответ `{"error": "forbidden"}`.** На бесплатном домене работает базовая защита (WAF); если она режет нормальные запросы — напишите в поддержку Amvera.
- **Данные пропали после пересборки.** Почти наверняка не задана переменная `DATA_DIR=/data`.
- **Резервные копии.** Amvera делает собственные копии `/data`, но раз в неделю-две всё равно скачивайте копию в админке — это ваша страховка.
